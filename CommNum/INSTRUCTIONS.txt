UTILISATION
-----------

1. GÉNÉRATION AUTOMATIQUE COMPLÈTE
   Double-cliquer sur: generer_tout.bat
   
   Ce script va:
   - Exécuter tous les scripts MATLAB
   - Générer toutes les images dans images/
   - Compiler le rapport PDF
   - Ouvrir le PDF automatiquement

2. GÉNÉRATION MANUELLE DES IMAGES
   Double-cliquer sur: generer_images.bat
   
   Ou dans MATLAB:
   >> cd codes
   >> generer_toutes_images

3. COMPILATION DU RAPPORT UNIQUEMENT
   cd rapport
   compiler_rapport.bat

4. TEST D'UNE QUESTION SPÉCIFIQUE
   Dans MATLAB:
   >> cd codes
   >> test_Q1_Q2    % Tester Q1 et Q2
   >> test_Q3       % Tester Q3
   >> test_Q4_Q5    % Tester Q4 et Q5
   >> test_Q6       % Tester Q6
   >> test_Q7_emetteur  % Tester Q7

TROUBLESHOOTING
---------------
Problème: MATLAB ne trouve pas les fonctions
Solution: Vérifier que vous êtes dans le dossier codes/

Problème: Images non générées
Solution: Vérifier que le dossier images/ existe
          Exécuter: mkdir ../images dans MATLAB

Problème: Erreur de compilation LaTeX
Solution: Vérifier que les chemins vers les images sont corrects
          Vérifier que les logos sont dans ../../ressources/

Problème: "File not found" pour les logos
Solution: Copier les logos depuis le dossier principal:
          copy ..\ressources\*.png ressources\
